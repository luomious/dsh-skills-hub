# Paper Summary（论文速读与总结）

用「四段式 + 关键证据」结构输出论文总结，忠实原文、不编造数据。

## 结构

1. **一句话核心**：这篇论文解决了什么问题、用什么方法、达到什么效果（≤2 句）。
2. **动机与问题**：研究背景、要解决的具体痛点、与已有工作（baseline）的差距。
3. **方法**：按模块讲清 pipeline/核心思想；公式与算法给出直观解释而非照抄；标注创新点（相对已有工作）。
4. **实验与结论**：数据集、评估指标、主要数字（引原文数值）、消融实验说明什么；作者结论与主张。
5. **局限与启发**：数据/方法/泛化上的局限；对读者自己工作的可借鉴点（如果用户需要）。

## 规则

- **忠于原文**：数字、方法名、结论必须可溯源到原文；不确定处标注「原文未明确/需核对」。
- **术语处理**：专业术语首次出现给出中文释义 + 英文原名；缩写给出全称。
- **引用格式**：`[§x.y] 原文页码/章节`，让用户能回到原文核对。
- **不替作者下结论**：评价时区分「原文主张」与「你的看法」。

## 适用变体

- 只要要点 → 输出「一句话核心 + 关键数字表」。
- 要讲读 → 在方法部分展开，用类比解释机制。
- 要批判 → 增加「方法漏洞 / 复现风险」小节，逐条列证据缺口。
